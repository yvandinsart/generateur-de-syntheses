☁️ Mise à jour des synthèses via GitHub

Après avoir modifié une synthèse dans PowerPoint, vous pouvez remplacer directement la version stockée dans votre dépôt GitHub. La nouvelle version sera alors disponible depuis tous vos PC.

Renseignez votre dépôt GitHub et votre jeton d’accès. Sur GitHub Pages, le dépôt peut souvent être détecté automatiquement.
Sécurité : le jeton n’est jamais écrit dans le fichier HTML ni envoyé ailleurs qu’à l’API GitHub. Il est mémorisé uniquement dans ce navigateur si vous cochez l’option ci-dessous.
Comment créer le jeton GitHub ?

Créez un fine-grained personal access token limité uniquement à ce dépôt avec la permission Contents: Read and write. Vous pourrez révoquer ce jeton à tout moment depuis GitHub.
